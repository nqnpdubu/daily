# daily

One commit every day. Code for life.

A creative coding practice: small programs about curiosity — simulations,
generative art, tiny games, little tools, strange experiments. One a day,
no pressure, just play.

Rules:
- One commit per day on `main`: `daily: <what> (YYYY-MM-DD)`
- Small, zero dependencies, original work
- `log.md` gets one line per day; `ideas.md` holds the queue
